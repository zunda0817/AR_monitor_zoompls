# AR Monitor Touch — Office画面を指先で操作するARアプリ

Webカメラでモニターまたは白い紙の四隅を検出し、PowerPointなどのOffice画面をカメラ映像上に重ねて表示するWindows用Pythonアプリです。画面に向けた指先でマウス操作やズーム、スワイプができます。

## 重要：Webカメラの画面を見ながら操作するにはモニターが2台必要です

**Office画面とWebカメラのプレビュー画面を同時に表示して操作する場合は、モニターを2台用意してください。**

- **モニター1（操作対象）**：PowerPointなどのOffice画面を表示します。Webカメラは、このモニター（または操作したい白い紙）を撮影します。
- **モニター2（確認用）**：PythonアプリのWebカメラ映像（ARプレビュー）を表示します。指先や四隅の認識状況を見ながら操作します。

1台のモニターでOffice画面とプレビューを重ねると、**プレビュー自身が再びカメラや画面キャプチャに映り込む「画面の再帰表示」**が起きたり、操作対象が隠れたりすることがあります。2台構成は、こうした問題を避けるための推奨構成です。

> 2台のモニターは、カメラ映像を確認しながら安定して操作するための構成です。プログラムの起動そのものが必ず2台を要求するわけではありません。

## 1. 必要なもの

- Windows PC
- Webカメラ（内蔵・USB接続のどちらでも可）
- **モニター2台**（Webカメラのプレビューを見ながら操作する場合）
- Python 3.10〜3.12（推奨。MediaPipe 0.10.21を使用）
- PowerPoint、Excel、Wordなど、操作するOfficeアプリ
- インターネット接続（初回のライブラリインストール時）

## 2. インストール方法

1. このREADMEと同じフォルダに、`smart_monitor_office_native_zoom_two_hands_zoom_click_v2.py` を保存します。
2. VS Codeなどでそのフォルダを開き、PowerShellターミナルを起動します。
3. Pythonのバージョンを確認します。

```powershell
python --version
```

4. 必要なライブラリをインストールします。

```powershell
python -m pip install opencv-python numpy mediapipe==0.10.21 pyautogui pywin32 mss
```

Pythonが見つからない場合は、Pythonをインストールし、ターミナルを開き直してください。

## 3. 起動方法

1. モニター1にPowerPointなどのOfficeウィンドウを表示します。**ウィンドウは最小化しないでください。**
2. Webカメラが対象モニター全体（または白い紙）を映すように設置します。
3. ターミナルで次のコマンドを実行します。

```powershell
python smart_monitor_office_native_zoom_two_hands_zoom_click_v2.py
```

4. ターミナルにOfficeウィンドウ一覧が表示されたら、操作対象の番号を入力してEnterを押します（通常は`1`を選択）。
5. 開いたWebカメラのプレビューウィンドウを**モニター2に移動**します。
6. モニターの四隅が自動認識されると、対象領域にOffice画面が合成されます。白い紙を使う場合は`2`キーで切り替えます。
7. **`E`キー**で操作をONにして、指先操作を始めます。

> キーボードのショートカットは、基本的に**Webカメラのプレビューウィンドウを選択した状態**で押してください。

## 4. 指先による操作

| 操作 | 動作 |
| --- | --- |
| 人差し指1本を動かす | Office画面上のマウスカーソルを移動 |
| 人差し指1本を約0.38秒静止 | クリック |
| 人差し指1本を左へ素早くスワイプ | 次のスライドへ移動（PowerPointスライドショー時） |
| 人差し指1本を右へ素早くスワイプ | 前のスライドへ移動（PowerPointスライドショー時） |
| **片手の人差し指と中指**を広げる／狭める | ズームイン／ズームアウト |
| **両手の人差し指同士**を広げる／狭める | ズームイン／ズームアウト |

**クリックのコツ：** ズームを終了したら人差し指だけを伸ばし、中指は曲げます。両手でズームした場合は片方の手をカメラの範囲から外し、人差し指をクリックしたい位置で静止させてください。2本指のズーム判定中は誤クリック防止のためクリックしません。

**ズームについて：** このアプリはAR映像だけを拡大するのではなく、**Officeモードでは`Ctrl + マウスホイール`、DESKTOPモードではWindowsの拡大鏡**を操作します。Officeアプリの種類や表示モードによってはズームが効かない場合があります（特にPowerPointスライドショー）。

## 5. キーボード操作

| キー | 機能 |
| --- | --- |
| `1` | モニター認識モード |
| `2` | 白い紙の認識モード |
| `E` | マウス・ジェスチャー操作のON/OFF |
| `G` | ズーム対象を切り替える（Office／Windows拡大鏡） |
| `M` | 四隅を手動指定するモード |
| `A` | 四隅の自動検出へ戻る |
| `D` | 輪郭検出のデバッグ表示ON/OFF |
| `S` | プレビュー画像を保存 |
| `Q` または `Esc` | プログラムを終了 |

**四隅の手動指定：** `M`を押し、プレビュー画面上で対象の**左上 → 右上 → 右下 → 左下**を順にクリックします。自動認識へ戻したい場合は`A`を押してください。

**Windows拡大鏡を終了：** `Windows + Esc` を押します。拡大鏡モードでは見た目の座標とクリック位置が一致しなくなる場合があるため、通常はOfficeモードをおすすめします。

## 6. よくあるトラブル

| 症状 | 対処方法 |
| --- | --- |
| `Office window not found` | Officeファイルを開き、ウィンドウを最小化しないで再実行する |
| カメラが起動しない | Teams・Zoomなどを閉じ、Windowsのカメラ権限を確認する |
| 違うカメラが起動する | PowerShellで`$env:SMART_CAMERA_ORDER="0,1,2,3"`を実行してから再起動する |
| 四隅を認識しない | 対象全体をカメラに収める／照明や背景を調整する／`M`で手動指定する |
| マウスが動かない | 四隅を検出後、プレビュー画面で`E`を押して操作をONにする |
| ズームはできるがクリックできない | 指を1本に戻し、0.38秒程度静止する。もう片方の手をカメラ外に出す |
| ズームが動かない | `G`でモードを確認し、Office編集画面で試す。操作対象ウィンドウを選択する |
| プレビューが何重にも映る | Office画面とプレビューを別々のモニターに表示する |

## 7. 感度の調整（必要な場合）

Pythonファイルの先頭付近にある数値を変更できます。変更後は保存し、プログラムを再起動してください。

```python
HOLD_SECONDS = 0.38                # 小さくするとクリックが早くなる
STILL_RADIUS = 38.0                # 大きくすると指先の揺れを許容しやすい
PINCH_STEP_RATIO = 1.12            # 小さくすると少ない開閉でズームする
OFFICE_WHEEL_TICKS_PER_STEP = 3    # 大きくすると1回のOfficeズーム量が増える
DESKTOP_MAGNIFIER_KEYS_PER_STEP = 2
```

## 8. 注意事項

- **Windows専用**のアプリです。
- 指先認識は照明、手の向き、カメラの画質、対象の遮蔽などの影響を受けます。
- Officeのウィンドウ取得が正常に動作しない環境もあります。
- `E`キーでマウス操作をOFFにできます。予期しない操作が起きた場合は`Q`や`Esc`でアプリを終了してください。
- 画面の端へマウスカーソルを移動すると、PyAutoGUIのフェイルセーフが発動する場合があります。

---

本アプリは、輪郭検出・ホモグラフィ変換・MediaPipe Handsを組み合わせ、一般的なWebカメラでAR型の画面操作を試みる実験用プロジェクトです。
